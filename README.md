## 🚀 Proyecto principal: RehabOT

Aplicación web para terapeutas ocupacionales, en prueba piloto con profesionales reales.

**Qué hace:** gestión de pacientes, sesiones clínicas y mediciones (goniometría, dinamometría, circometría).

**Base de datos:** PostgreSQL con campos JSONB y seguridad a nivel de fila (RLS).

**Stack:** React · Vite · Supabase

*Repositorio privado por tratarse de un producto en desarrollo con datos clínicos.*
